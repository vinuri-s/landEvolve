# JIT-compiles the corrected SpaceLargeScaleEroder inner loop (see
# app/engine/space_fix.py) that fixes a confirmed Landlab numerical bug
# (landlab/landlab#1901 neighbourhood) -- a floating-point exact-equality
# check that should be a tolerance check, which can otherwise produce
# non-physical elevation spikes on gently-sloping terrain. Prebuilt wheels
# on PyPI for all platforms (no C++ compiler needed). Not strictly required
# -- if missing, the engine falls back to Landlab's original code, still
# protected by the statistical outlier guard in components.py, just without
# the root-cause fix.
numba

# Elastic-dislocation (Okada 1992) solver used by the fault / earthquake /
# landslide processes (vendored EFEL model in app/engine/efel). Not on PyPI, so
# it is built from source: needs git and a C++ compiler (Xcode command-line
# tools on macOS, MSVC Build Tools on Windows, build-essential on Linux).
# The app still starts without it -- only those three processes then refuse to
# run, with a message saying how to install it.
# numpy>=2 (above) is also required by EFEL (it uses numpy 2-only functions).
okada4py @ git+https://github.com/jolivetr/okada4py.git
